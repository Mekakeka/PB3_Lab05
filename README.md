# PB3_Lab05

PB3_Lab05

Лабораторної робота № 5

Тема: Робота з фреймворками для верстання

Мета: опанувати принципи адаптивної верстки, навчитися використовувати
гнучку сітку (Grid System) та готові компоненти Bootstrap, закріпити навички
створення сторінок, що коректно відображаються на різних пристроях,
налаштувати фіксований елемент шапки та реалізувати логічні анімації при
прокручуванні сторінки. Верстка виконується за варіантом із практичної
роботи No 3, яку переписано з використанням Bootstrap.
